# 术语表

| 术语 | 全称 | 含义 |
|---|---|---|
| PTQ | Post-Training Quantization | 训练后量化 |
| PTP | Post-Training Pruning | 训练后剪枝 |
| TTFT | Time To First Token | 首 Token 延迟 |
| TPOT | Time Per Output Token | 单输出 Token 时间 |
| ITL | Inter-token Latency | Token 间延迟 |
| KV Cache | Key-Value Cache | 自回归解码中的注意力缓存 |
| TP | Tensor Parallelism | 张量并行 |
| PP | Pipeline Parallelism | 流水线并行 |
| EP | Expert Parallelism | 专家并行 |
| DDP | Distributed Data Parallel | 分布式数据并行 |
| FSDP | Fully Sharded Data Parallel | 完全分片数据并行 |
| NCCL | NVIDIA Collective Communications Library | GPU 集合通信库 |
| HBM | High Bandwidth Memory | GPU 高带宽显存 |
| SLO | Service Level Objective | 服务等级目标 |
