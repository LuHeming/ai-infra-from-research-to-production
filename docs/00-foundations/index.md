# 工程基础

这一部分用于建立可复现、可调试、可协作的实验环境。

## 必须掌握

- Linux 文件、进程、权限和日志
- SSH、tmux、rsync
- Git 分支、提交、PR 和冲突处理
- Python 包结构、配置、日志和测试
- CUDA Driver、CUDA Toolkit、PyTorch 的版本关系
- 实验随机种子、依赖锁定和环境记录

## 学习产出

- 一份可复用的环境检查清单
- 一个能够通过命令行运行的实验项目
- 一个包含测试和日志的最小工程

## 推荐顺序

1. [Linux 工程基础](linux-fundamentals.md)：文件、进程、资源、网络与远程开发。
2. [开发环境与可复现性](development-environment.md)：记录版本、命令、输入与结果。
3. [PyTorch 性能分析](../01-pytorch/profiler.md)：从系统观察进入算子级分析。
